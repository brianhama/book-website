About this website

Outside of books assigned for school, I was never much of a reader growing up. Back in 2012, I decided to change that and set a goal of reading one book a month for a year. I got hooked. Since then, I've read over 1,500 books.

This website is a collection of the best books I've read. Nearly all of my reading happens in audiobook form, and every book recommended here is available as an audiobook. I've organized them by category and added a short description of each book. I don't necessarily agree with the premise of every book here, but I find seeing things from multiple perspectives interesting. My hope is that someone is able to get as much from these books as I have. Also, if you have any recommendations, please let me know!
